# Дневник смен водителя

Мини-проект для тестового задания arqa. API и адаптивный веб-клиент на FastAPI; данные хранятся в JSON-файле.

## Запуск

Требуется Python 3.9 или новее.

```bash
cd arqa-shift-diary
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload
```

Откройте http://127.0.0.1:8000. Интерактивная схема API доступна по `/docs`.

## Что сделано

- `GET /api/days` возвращает дни, найденные в данных.
- `GET /api/trips?day=2026-10-01` и `GET /api/summary?day=2026-10-01` отдают поездки и сводку.
- `POST /api/trips` проверяет положительную сумму и интервал времени, принимает `cash` или `card`.
- Повтор с тем же ID идемпотентен; при отсутствии ID ключ стабильно выводится из содержимого поездки. Совпавший ID с другими данными возвращает 409.
- Веб-страница показывает сводку, поездки, переключатель дат и форму добавления.
- Исходные примеры дают 2 поездки, выручку 3 900 ₸, комиссию 585 ₸ и на руки 3 315 ₸.

## Использование ИИ

ИИ помог быстро подготовить каркас API, валидацию, веб-интерфейс и тесты. Я отдельно проверил расчёт на примере задания и добавил стабильную дедупликацию повторной отправки, потому что случайный ID не защищал бы от сетевого повтора. В реальном приложении я бы заменил файловое хранилище на транзакционную базу данных и сохранил ключ идемпотентности как уникальное ограничение.
